# Explore With Me API

API дополнительной фичи к сервису "Explore With Me" предоставляет возможность управления комментариями к публикуемым событиям. Сервис поддерживает три уровня доступа: публичный, приватный и административный. Основная функциональность включает создание, обновление, удаление и поиск комментариев, а также возможность публикации ответов на комментарии.
[Подробная спецификация](https://github.com/tutrahamonkz/java-explore-with-me-plus/blob/feature_comments/ewm-stats-service-spec.json)

## Описание API

### Основная информация
- **Версия API:** 1.0
- **Базовый URL:** `http://localhost:8080`
- **Описание:** Документация API для работы с комментариями событий.

### Теги API
1. **Public: Комментарии событий**  
   Публичный API для работы с комментариями событий.
2. **Private: Комментарии событий**  
   Приватный API для работы с комментариями событий (доступен только авторизованным пользователям).
3. **Admin: Комментарии событий**  
   API для администраторов, позволяющий управлять комментариями событий.

## Основные эндпоинты

### 1. Публичный API

#### Получение комментариев к событию
- **GET `/events/{eventId}/comments`**  
  Возвращает все комментарии к указанному событию.  
  **Параметры:**
  - `eventId` (обязательный) — ID события.  
  **Ответ:**
  - `200` — Комментарии найдены. Возвращает список объектов `CommentDto`.
  - `400` — Запрос составлен некорректно.

#### Получение ответов на комментарий
- **GET `/comments/{commentId}/replies`**  
  Возвращает все ответы на указанный комментарий.  
  **Параметры:**
  - `commentId` (обязательный) — ID комментария.  
  **Ответ:**
  - `200` — Ответы найдены. Возвращает список объектов `CommentDto`.
  - `400` — Запрос составлен некорректно.

---

### 2. Приватный API

#### Добавление нового комментария
- **POST `/users/{userId}/comments`**  
  Позволяет пользователю добавить новый комментарий к событию.  
  **Параметры:**
  - `userId` (обязательный) — ID текущего пользователя.  
  **Тело запроса:**  
  Объект `NewCommentDto` с текстом комментария и ID события.  
  **Ответ:**
  - `201` — Комментарий успешно добавлен. Возвращает объект `CommentDto`.
  - `400` — Запрос составлен некорректно.
  - `409` — Нарушение целостности данных.

#### Получение комментария по ID
- **GET `/users/{userId}/comments/{commentId}`**  
  Возвращает комментарий по его ID.  
  **Параметры:**
  - `userId` (обязательный) — ID текущего пользователя.
  - `commentId` (обязательный) — ID комментария.  
  **Ответ:**
  - `200` — Комментарий найден. Возвращает объект `CommentDto`.
  - `400` — Запрос составлен некорректно.
  - `404` — Комментарий не найден.

#### Изменение комментария
- **PATCH `/users/{userId}/comments/{commentId}`**  
  Позволяет пользователю изменить текст своего комментария.  
  **Параметры:**
  - `userId` (обязательный) — ID текущего пользователя.
  - `commentId` (обязательный) — ID изменяемого комментария.  
  **Тело запроса:**  
  Объект `UpdateCommentDto` с новым текстом комментария.  
  **Ответ:**
  - `200` — Комментарий успешно обновлен. Возвращает объект `CommentDto`.
  - `400` — Запрос составлен некорректно.
  - `404` — Комментарий не найден.
  - `409` — Комментарий не удовлетворяет правилам редактирования.

#### Удаление комментария
- **DELETE `/users/{userId}/comments/{commentId}`**  
  Позволяет пользователю удалить свой комментарий.  
  **Параметры:**
  - `userId` (обязательный) — ID текущего пользователя.
  - `commentId` (обязательный) — ID удаляемого комментария.  
  **Ответ:**
  - `204` — Комментарий успешно удален.
  - `404` — Комментарий не найден.

#### Добавление ответа на комментарий
- **POST `/users/{userId}/comments/{commentId}/reply`**  
  Позволяет пользователю добавить ответ на существующий комментарий.  
  **Параметры:**
  - `userId` (обязательный) — ID текущего пользователя.
  - `commentId` (обязательный) — ID комментария, на который добавляется ответ.  
  **Тело запроса:**  
  Объект `NewCommentDto` с текстом ответа.  
  **Ответ:**
  - `201` — Ответ успешно добавлен. Возвращает объект `CommentDto`.
  - `400` — Запрос составлен некорректно.
  - `409` — Нарушение целостности данных.

### 3. Административный API

#### Изменение комментария администратором
- **PATCH `/admin/comments/{commentId}`**  
  Позволяет администратору изменить текст любого комментария.  
  **Параметры:**
  - `commentId` (обязательный) — ID изменяемого комментария.  
  **Тело запроса:**  
  Объект `UpdateCommentDto` с новым текстом комментария.  
  **Ответ:**
  - `200` — Комментарий успешно обновлен. Возвращает объект `CommentDto`.
  - `400` — Запрос составлен некорректно.
  - `404` — Комментарий не найден.
  - `409` — Комментарий не удовлетворяет правилам редактирования.

#### Удаление комментария администратором
- **DELETE `/admin/comments/{commentId}`**  
  Позволяет администратору удалить любой комментарий.  
  **Параметры:**
  - `commentId` (обязательный) — ID удаляемого комментария.  
  **Ответ:**
  - `204` — Комментарий успешно удален.
  - `404` — Комментарий не найден.

## Модели данных

### CommentDto
- **id** (integer, int64) — ID комментария.
- **user** (UserShortDto) — Краткая информация о пользователе.
- **created** (string) — Дата и время создания комментария (формат `yyyy-MM-dd HH:mm:ss`).
- **eventId** (integer, int64) — ID события.
- **description** (string) — Текст комментария.
- **parentCommentId** (integer, int64) — ID родительского комментария (если есть).
- **replies** (array) — Список ответов на комментарий.

### NewCommentDto
- **description** (string) — Текст комментария.
- **eventId** (integer, int64) — ID события.
- **commentId** (integer, int64) — ID комментария (для ответов).

### UpdateCommentDto
- **description** (string) — Новый текст комментария.

### UserShortDto
- **id** (integer, int64) — ID пользователя.
- **name** (string) — Имя пользователя.

### ApiError
- **status** (string) — Код статуса HTTP-ответа.
- **reason** (string) — Общее описание причины ошибки.
- **message** (string) — Сообщение об ошибке.
- **timestamp** (string) — Дата и время ошибки (формат `yyyy-MM-dd HH:mm:ss`).
